# Support

Thanks for using **WRL Forge**. This is a **beta community project**, and support is
**best-effort** — provided by volunteers as time allows. There is no paid support, SLA, or
guaranteed response time.

WRL Forge is an independent community project and is **not affiliated with, endorsed by, or
officially connected to Cybertown**.

## Before you ask

Please check the documentation first — many questions are already answered there:

- **Installation:** [`docs/INSTALLATION.md`](docs/INSTALLATION.md)
- **Troubleshooting:** [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)

## Getting help

- **Questions, ideas, and general discussion:** use **GitHub Discussions** on the repository —
  <https://github.com/DJAscendance/wrlforge/discussions>. This is the best place for "how do
  I…", usage questions, and community help.
- **Bug reports and VRML compatibility reports:** use the issue forms —
  <https://github.com/DJAscendance/wrlforge/issues/new/choose>. Please pick the form that
  matches your report and fill in the details it asks for.

## Security issues

Do **not** report security vulnerabilities through Discussions or public issues. Follow the
private process in [`SECURITY.md`](SECURITY.md) instead.

## A note on beta software

WRL Forge is prerelease, **beta**, and **unsigned**. Expect rough edges. On Windows, unsigned
builds may trigger a SmartScreen/Defender warning ("More info → Run anyway"); see the
troubleshooting docs for details. Reporting what you run into helps make the tool better.
